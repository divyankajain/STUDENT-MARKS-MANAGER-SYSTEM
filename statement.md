# Student Marks Manager System

## Problem Statement

Managing student marks manually can be time-consuming and may lead to calculation errors. Teachers and users need a simple system to store student marks, calculate total and average marks, and determine grades efficiently. The Student Marks Manager System provides a simple solution for managing and organizing student academic records.

## Scope of the Project

The project focuses on managing student marks and academic information. It allows users to enter student details and marks, calculate total and average marks, and determine grades. The system can be further enhanced in the future with features such as data storage, search, reports, and user authentication.

## Target Users

- Teachers and faculty members
- Students
- Academic administrators
- Users who need to manage student marks and academic records

## High-Level Features

- Add student details
- Enter student marks
- Calculate total marks
- Calculate average marks
- Determine student grades
- Display student performance
- Manage student academic records
