# Student Marks Manager System

## Project Overview

Student Marks Manager System is a simple application designed to manage student academic records efficiently. It allows users to enter student details and marks, calculate total and average marks, and determine grades based on student performance.

## Features

- Add student details
- Enter student marks
- Calculate total marks
- Calculate average marks
- Determine student grades
- Display student performance
- Manage student academic records

## Technologies / Tools Used

- Python
- VS Code
- Git
- GitHub
